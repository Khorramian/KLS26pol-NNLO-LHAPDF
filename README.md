
# KLS26pol NNLO Polarized Parton Distribution Functions

This repository provides the polarized parton distribution functions (PPDFs)
determined from a next-to-next-to-leading order (NNLO) QCD analysis of
polarized inclusive deep-inelastic scattering (DIS) data.

The analysis includes target-mass corrections (TMCs), higher-twist (HT)
effects, and a detailed investigation of the impact of the nonsinglet
axial-charge constraints on the extracted polarized parton distributions.

All PDF sets are provided in the standard LHAPDF6 format and include
the complete Hessian uncertainty eigenvector sets.


## Reference

The PDF sets correspond to the NNLO QCD analysis presented in:

 J. Shahrzad, E. Leader and A. Khorramian 

"NNLO determination of polarized parton distribution functions with
higher-twist corrections and axial-charge constraints"

(to appear in Physical Review D)

arXiv:XXXX.XXXXX


## Available PDF Sets

Four polarized PDF ensembles are provided:

| PDF set | Higher-twist treatment | Axial-charge treatment |
|---|---|---|
| KLS26pol_AddHT_Fixed_a3_a8 | Additive HT | Fixed \(a_3,a_8\) |
| KLS26pol_MultHT_Fixed_a3_a8 | Multiplicative HT | Fixed \(a_3,a_8\) |
| KLS26pol_AddHT_Free_a3_a8 | Additive HT | \(a_3,a_8\) treated as free parameters |
| KLS26pol_MultHT_Free_a3_a8 | Multiplicative HT | \(a_3,a_8\) treated as free parameters |
